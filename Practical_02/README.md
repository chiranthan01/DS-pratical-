# Practical 02: Descriptive Statistics

**Dataset:** Datasets/TeachingRatings.csv (463 rows, 13 columns)

**Aim:** Understand the dataset type and compute descriptive statistics.

## Steps

1. Load the data and check its structure.
2. Identify the dataset type.
3. Find mean, median, minimum and maximum of students.
4. Produce the descriptive statistics table.
5. Plot a histogram of beauty score.
6. Compare beauty score by gender.
7. Cross-tabulate gender and tenure.

## Results

- The dataset is cross-sectional.
- Students: mean 36.62, median 23, minimum 5, maximum 380.
- Beauty score skewness is 0.516 (slightly right skewed).
- Beauty mean: female 0.1161, male -0.0845. Standard deviation: female 0.8178, male 0.7571.
- Tenure: 80.6% of men and 74.36% of women.

## How to run

Open the notebook in the same folder with Jupyter Notebook or Google Colab and run all cells. The data is read from the Datasets folder one level above.

Required libraries: pandas, numpy, matplotlib, scipy.
